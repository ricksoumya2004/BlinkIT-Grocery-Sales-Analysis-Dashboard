# BlinkIT Grocery Sales Analysis Dashboard

## 📊 Project Overview

This project presents an **Excel-based BlinkIT Grocery Sales Analysis Dashboard** developed to analyze sales performance across different products, outlet types, outlet locations, and other business dimensions.

The dashboard transforms raw grocery sales data into meaningful visual insights using **Microsoft Excel, Pivot Tables, KPIs, and data visualization techniques**.

---

## 🎯 Business Objective

The main objective of this project is to analyze grocery sales data and identify important patterns related to:

* Product categories and item types
* Fat content
* Outlet characteristics
* Outlet location
* Outlet size
* Outlet establishment year
* Sales performance

The analysis helps understand which products and outlet segments contribute most to overall sales.

## 📌 Dashboard Components

The dashboard includes the following visualizations:

### 1. Sales by Fat Content

Compares sales generated by products based on their fat-content classification.

### 2. Sales by Outlet Location Tier

Analyzes sales performance across different outlet location tiers.

### 3. Sales by Item Type

Shows the contribution of different grocery product categories to total sales.

### 4. Sales by Outlet Establishment Year

Analyzes sales performance based on the year in which outlets were established.

### 5. Sales by Outlet Size

Compares sales across different outlet-size categories.

### 6. Sales by Outlet Type

Analyzes sales generated by different types of outlets.

### 7. Average Sales by Outlet Type

Compares the average sales performance of different outlet types.

---

## 📈 Key Insights

* The dataset contains **8,523 grocery item records**.
* Total sales in the source dataset are approximately **1.20 million**.
* **Supermarket Type 1** contributes the highest sales among the outlet types shown in the dashboard.
* **Regular-fat products** contribute slightly higher sales than Low-Fat products in the analyzed data.
* **Tier 3 outlets** show the highest sales contribution among the location tiers.
* The dashboard indicates **2018** as the highest-sales establishment year in the displayed analysis.
* Outlet type and location play an important role in overall sales performance.
* The dashboard provides a quick way to compare product-level and outlet-level sales performance.
